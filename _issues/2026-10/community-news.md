## Security Updates

[php2shell](https://www.php2shell.com/) caused many sites across the world to go into panic mode and taken offline for emergency security updates. RetroAchievements was among that long list, and therefore had its servers taken offline on the 21st for longer than initially anticipated. With advances in AI, it seems probable that security updates will be a recurring theme over the coming year. We may start having regular biweekly ~45min maintenance windows to account for this sort of thing. We appreciate everyone's patience on this matter.

## Site Updates

### RAWeb 2026.10.09

This release, and several subsequent releases from here, is primarily focused on making improvements to the ticket system.

**New Features**
The "Report issue" page for achievements has received a restyle to hopefully make it more clear what button should be pressed.
We now do a better job of clarifying that tickets are not manual unlock requests.
We've made a bunch of changes to the ticket list: bigger text, and filter options for system, core, and resolution type.

**Highlights for Contributors**
The new collab claims policy is now enforced by the server code.

[Full release notes](https://github.com/RetroAchievements/RAWeb/releases/tag/2026.10.9)

### RAWeb 2026.10.31

**New Features**
We've launched our new [ticket details page](https://retroachievements.org/ticket/119684). The new page has many changes and gives us a solid foundation to continue improving the ticket system.
Hashes now link to a resource page URL if one is provided.

**Bug Fixes**
Subset pages now properly show event achievement indicators.

**Highlights for Developers**
"Ticket signals" is a new feature we've added that's visible only to Developers and Junior Developers. We now show an indicator if our back-end stats suggests a ticket is or isn't actually a real bug. See [here](https://github.com/RetroAchievements/RAWeb/pull/5307) for more info and the methodology.
Ticket lists themselves can now be filtered by signals. See [here](https://github.com/RetroAchievements/RAWeb/pull/5313) for more info.

[Full release notes](https://github.com/RetroAchievements/RAWeb/releases/tag/2026.10.31)
