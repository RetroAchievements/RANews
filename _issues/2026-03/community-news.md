## Wii Is Here!!

Wii are extremely happy to welcome you to our biggest rollout ever with over 180 sets! RetroAchievements is proud to announce support for our 53rd console, the Nintendo Wii!

**To start earning achievements for Wii, as well as GameCube in Hardcore mode, you need to be on version 2603a or later, or 2603-81+ for Nightly. Use the auto-updater, or get a new version directly from [https://dolphin-emu.org/](https://dolphin-emu.org/).**

It has already been two years since our last rollout huh? Two years ago, we were working together with the Dolphin team on bringing GameCube to our platform (which was our previous biggest rollout!), and our community has grown exponentially since then. Of course as with every rollout, people were starting to wonder what's next; would it be what we teased in the previous post with older computers like ZX Spectrum and Commodore 64, or was the answer in front of us after all with the Nintendo Wii? We kept it a secret for long, until we revealed it last year after thorough testing that we would in fact continue the legacy of Nintendo!

A massive thank you to the Dolphin team, the Rollout team for organizing the rollout, the Writing team for reviewing every set, and of course all of our fantastic developers who have made these sets for all your childhood favorites! Be sure to leave them a nice comment, they deserve it

Come hang out in the ⁠`#🐬｜wii-channel` to discuss all the games or the Wii launch event that will be running for the coming 4 months!

## Multiset

Multiset is a feature that has been in development for over a year that allows you to earn subset achievements without requiring a patched ROM. This has been a very highly requested feature for several years. You will need RetroArch 1.22.1+ or the absolute latest version of RALibRetro. This is a bleeding edge feature that requires a complete emulator upgrade as well as the latest cores. Only the latest emulators can talk to our back-end correctly to partake in multiset functionality.

More details and multiset can be found [here](https://retroachievements.org/forums/topic/34021).

## Site Updates

### RAWeb 2026.02.05

**New Features**
- We've launched RetroPoints 2.0 and updated all RetroPoints values for players and achievements on the site. Learn more about the new algorithm here. An ELI5 is attached to this announcement.
- Game banners now support "expanded mode" in addition to "compact mode". On desktop, just click the line underneath the banner to change its size. You can rotate through 3 different sizes.

**Bug Fixes**
- We've made some tweaks to compromised password alerts so they're less noisy.
- We've fixed an issue where some event achievement pages would crash.
- The navbar will no longer randomly go invisible when navigating away from some game pages.
- We've fixed an issue where the number of trending games would sometimes drop from 4 to 1 for no reason.

**Highlights for Contributors (Management App)**
- Developers can now delete any credit on their own achievements.
- We've fixed a bug where set type changes would disable multiset for a game.
- We now log all credit and multiset changes in the audit log.
- Leaderboards now have a merge tool(!!). You can use this tool to merge two identical leaderboards, which may be helpful for improving the multiset experience for games where a leaderboard is duplicated between the base set and a subset.

[Full release notes here](https://github.com/RetroAchievements/RAWeb/releases/tag/2026.02.05)

### RAWeb 2026.02.20
This is a big release with many changes for players and devs.

**New Features**
- Game Lists: We've added new "Time to Beat" and "Beat %" columns, enabled using the "Columns" dropdown.
- Events: If you've won multiple awards for an event, you can now pick which badge to show on your profile.
- All game and event pages now use a fallback banner if the page doesn't have a custom banner yet. The fallback was contributed by @ZeeRA.
- Trending games now link to an event if the event is what caused the game to trend.

**Bug Fixes**
- Your banner height pref will now persist after closing your browser.
- We've fixed an issue where some Code Contributor credits weren't properly appearing on game pages.
- Event achievements are now filtered out of recent points stats on user profiles.

**Other Changes**
- After internal discussion, we've decided to remove the top-level "Achievements" menu from the navbar. The page is still accessible, just from a different place. You can view it by clicking the 'Unlocked Achievements' link in your user menu.
- We've adjusted the site's RetroPoints tooltip labels.

**Highlights for Contributors**
- We now warn players in their emulator if they're using DoubleCherryGB, snes9x2010, or dolphin_libretro. Tickets from these cores will be quarantined - you won't be notified about them, and they won't count towards your open tickets. More details here.
- Game & event pages have a new "Manage" button on the top right which eliminates a click.
- You can add video URLs to achievements again.
- QAM can now assign maintainers.
- Table filters won't unset anymore when reordering achievements and leaderboards.

[Full release notes here](https://github.com/RetroAchievements/RAWeb/releases/tag/2026.02.20)

## Emulation Updates
###  Famicom Disk System (FDS) is now its own system
- The FDS is a peripheral for the Famicom (Japanese NES) that works much like the Sega CD. It provides a way to access larger games (disks instead of CDs), and provides more system memory. There were roughly 200 games released for the FDS, about 2/3 of which are exclusive to the FDS.
- This separation helps us better map supported cores for the system, and provides a more accurate memory map for developers. The extra memory provided by the FDS showed up as Cartridge RAM and Cartridge ROM when FDS games were loaded against the NES memory map.
- Users playing NES games are not affected by this change. Users playing FDS titles will need to be on the latest RANes/RAlibretro with the latest DLL (if you've updated since mid-November, you should be on the latest versions). RetroArch and devices using RetroArch are not affected because it doesn't load the game through a specific system.
- As part of this change, the FDS versions of Super Mario Bros and The Legend of Zelda will be unlinked from their counterpart NES sets. This will happen approximately two weeks from now in case anyone is in the middle of a playthrough.
